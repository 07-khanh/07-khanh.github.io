Welcome to my new digital library. I built this space because I needed a dedicated area that combined the features of a blog with the organization of a notebook.

### Why not just use Notion or Substack?

While tools like Notion are great for private organization, and Substack is excellent for newsletters, neither provided the exact feeling I wanted for **public technical notes**. 

I wanted:
- First-class support for LaTeX mathematics $\int e^x dx$
- Code blocks with proper highlighting
- An editorial, book-like reading experience

Here's a quick Python snippet to test the syntax highlighting:

```python
def fibonacci(n):
    if n <= 1:
        return n
    return fibonacci(n-1) + fibonacci(n-2)
```
