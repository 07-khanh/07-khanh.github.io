# Core Concepts

Machine Learning is about building systems that learn from data.

### Types of ML Systems
* **Supervised Learning**: Training data includes desired solutions (*labels*).
* **Unsupervised Learning**: Unlabeled data (e.g., Clustering, Dimensionality Reduction).
* **Reinforcement Learning**: Agent observes environment, performs actions, and receives rewards/penalties.

### Main Challenges
1. Insufficient quantity of training data.
2. Nonrepresentative training data (sampling bias).
3. Overfitting: Model performs well on training data, but fails to generalize.
